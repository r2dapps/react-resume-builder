# RazelTech Resume Builder 🚀

![RazelTech Banner](https://img.shields.io/badge/RazelTech-Resume_Builder-blue?style=for-the-badge&logo=react)

A high-fidelity, print-perfect resume builder designed for professional excellence. Built by **RazelTech**, this tool focuses on 100% parity between your live preview and the final printed PDF.

## 🔗 Live Demo
**[Click here to build your resume!](https://r2dapps.github.io/react-resume-builder/)**

## ✨ Key Features
- **Print-First Design**: Engineered specifically for A4 paper dimensions with zero margin shifts.
- **High-Contrast Monochrome**: All templates are optimized for physical printing—no faded grays or fuzzy borders.
- **9+ Premium Templates**: Including Technology-focused, Executive, Creative, and ATS-friendly layouts.
- **Smart Page Breaks**: Automatic content protection prevents dates and descriptions from being sliced across pages.
- **Local Persistence**: Your data is saved locally in your browser, ensuring privacy and continuity.
- **Real-time Export**: Download as a professional PDF using native browser print engines for the highest possible quality.

## 🛠️ Technology Stack
- **Core**: React 19 + Vite
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Database**: Dexie.js (IndexedDB)
- **PDF Core**: jsPDF (for direct downloads)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/r2dapps/react-resume-builder.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 📦 Deployment
The project is configured for seamless deployment to GitHub Pages.

```bash
npm run deploy
```
*This command will automatically build the project and push it to the `gh-pages` branch.*
